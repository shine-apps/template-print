## 一、产品概述

### 1.1 产品定位

「模板打印」是一款运行在 Windows 电脑上的**可视化模板设计与批量套打工具**。用户可以自行设计任意尺寸的打印模板，在模板中预留「参数」（如姓名、日期、金额），每次打印时只需填写参数即可快速输出成品，实现「一次设计、反复填值、快速打印」。

产品官方自述（关于页原文）：

> 可视化模板设计与打印工具：自定义纸张尺寸，文本/图片/图形自由排版，参数占位自动填值，支持横排与竖排文本、仅打印文本（预印纸套打）、静默/弹框打印、打印历史与数据备份，适配标签机与普通办公打印机。

### 1.2 目标用户

- 有**固定版式、反复填写**打印需求的个人与小微团队：行政人事（证书、证明、工牌）、门店零售（价签、小票）、仓储物流（标签）、教培机构（结业证、通知书）等。
- 不具备专业设计/排版软件能力、希望「像摆积木一样」完成版式设计的普通办公用户。
- 需要在**普通办公打印机、标签/条码打印机、小票热敏打印机**上输出非标准纸张的用户。

### 1.3 典型使用场景

1. **可视化设计模板**：图文自由排版，纸张尺寸支持 A4/A3、58/80mm 小票、标签、证卡与任意自定义尺寸。
2. **参数化套打**：模板中预留姓名、日期等占位文本，打印时填参出件，适合预印纸张套打。
3. **模板库维护**：模板的分类、搜索、复制、重命名、删除、导入导出。
4. **基于已有模板调整打印**：打印前可随时跳转设计器微调版式，返回后已填参数不丢失。
5. **打印追溯与重打**：每次打印自动留档（含成品缩略图与参数内容），可筛选搜索、一键重打或直接重发。
6. **打印机管理**：枚举本机打印机、设置应用默认打印机、查看在线/缺纸/离线状态、打印测试页，并对非标准纸张给出设置引导。

### 1.4 产品范围

**在范围内：**

- 模板设计（文本、图片、直线、矩形、椭圆；横排/竖排；图层、吸附、网格、撤销重做）
- 参数化文本（四种参数类型、日期与数字格式化、空值时可显示参数名称/留空/占位横线）
- 两种打印模式（静默直打 / 系统对话框打印）与「仅打印文本」套打模式
- 打印历史、自动清理、重打
- 模板文件（.tplx）导入导出、数据备份（zip）
- 应用自动更新（含断点续传、完整性校验、失败自动回滚）

**明确不做（非目标）：**

- **不内置条码/二维码生成器**：条码、二维码需求通过上传图片元素满足。
- 不做用户账号、多用户权限、网络协同与云同步（纯本地单机应用）。
- 不做自动流水号、下拉选择参数、图片类型参数。
- 不做打印审批、计费、统计报表。
- 不做 macOS / Linux 适配，仅面向 Windows 验收。

### 1.5 产品形态与环境约束

- 本地桌面应用，所有数据保存在本机，不依赖网络即可完成核心功能（仅自动更新需要联网）。
- 仅支持 Windows；安装方式支持普通安装与企业批量部署安装。
- 应用窗口默认尺寸 1280×820，最小尺寸 1024×700。
- 窗口标题栏格式：`模板打印 V<版本号>`（如「模板打印 V0.9.4」）。
- **单实例运行**：应用已在运行时再次启动，会自动唤醒并前置已有窗口（最小化时也会恢复）。
- 正式安装后不显示系统菜单栏，界面以应用自身导航为准。

## 二、用户角色与权限说明

本产品为**单用户本地应用，没有账号体系、角色划分与权限模型**。任何能登录该 Windows 账户并启动应用的人，都拥有全部功能权限。

与「权限」相关的产品行为仅有两类：

| 场景 | 行为 |
| --- | --- |
| 日常使用 | 以当前 Windows 用户身份运行，模板、图片、设置、历史全部存储在该用户的个人数据目录下，不同 Windows 账户之间数据天然隔离。 |
| 安装 / 自动更新 | 安装新版本可能触发 Windows「用户账户控制（UAC）」提示，用户点击「是」授权后方可安装；更新流程中会明确提示这一点。整个更新仅需授权一次。 |

数据安全通过产品规则保障而非权限：删除模板、清空历史等不可逆操作均需二次确认；打印历史独立留存，删除模板不会连带销毁历史凭证。

## 四、功能模块详述

### 4.1 模板列表（首页）

#### 4.1.1 页面布局

- 整页内边距 16px；顶部为操作栏（与下方卡片间距 12px），下方为自适应卡片网格。
- 操作栏自左向右：
  1. **分类下拉**：占位文案「全部分类」，宽 140px，可清空；选项为当前模板库中实际出现过的分类（去重）。
  2. **搜索框**：占位文案「搜索模板名称」，宽 220px，可清空，输入即按模板名关键字检索。
  3. **「新建模板」主按钮**（带 + 号）：直接进入设计器的空白新建态。
  4. **「导入」按钮**：选择本机 .tplx 模板文件导入，成功提示「模板已导入」并刷新列表。

#### 4.1.2 模板卡片

- 网格按窗口宽度自动排列，卡片最小宽 200px，卡片间距 12px。
- 卡片自上而下包含：
  1. **封面缩略图**（高 156px）：按真实毫米坐标等比缩小渲染模板实际版式（文本、图片、图形均真实呈现）；缩略图中 `{{参数名}}` 占位符**原样显示并以浅蓝底、蓝字高亮**，便于辨识哪些模板含参数。
  2. **模板名称**。
  3. **描述行**：`分类 · 宽×高mm · 打印方式`，无分类显示「未分类」；打印方式显示「直打」（静默直打）或「弹框」。示例：`证书 · 210×297mm · 直打`。
  4. **操作区**：文字按钮「去打印」「编辑」，以及「⋯」更多菜单。
- 更多菜单顺序：「复制」「导出」「重命名」，分隔线，红色「删除」。

#### 4.1.3 卡片操作规则

| 操作 | 规则 |
| --- | --- |
| 去打印 | 携带该模板进入打印页。 |
| 编辑 | 进入设计器编辑该模板。 |
| 复制 | **不立即产生新模板**，而是以「原名 + 副本」（无空格，如「证书」→「证书副本」）生成一份内存草稿带入设计器；保存后才真正入库，保存时图片等资源自动复制，副本完全独立。 |
| 导出 | 下载导出 `<模板名>.tplx` 模板文件（内含模板完整定义与全部图片源文件）。 |
| 重命名 | 弹出「重命名」对话框，预填当前名称，回车或点确定保存；名称去除首尾空格后为空则不保存。 |
| 删除 | 二次确认，见下。 |

删除确认弹窗：

- 标题：`删除模板"{名称}"？`
- 正文：「图片资源将一并删除，已产生的打印历史保留。」
- 按钮：红色「删除」/「取消」；成功提示「已删除」。

#### 4.1.4 空状态

无任何模板时显示空状态插画与文案：`还没有模板，点"新建模板"开始`。

#### 4.1.5 导入规则

- 仅接受本产品 .tplx 模板文件；文件无效时给出错误提示。
- 导入**总是新建一份模板**：新模板名称自动追加「 导入」（如「证书 导入」），不覆盖同名模板；内置示例标记被清除，创建时间刷新。
- 包内图片随模板一并入库；与库内资源重复的图片自动跳过不重复保存；包内缺失的图片对应元素留空。

### 4.2 模板设计器

#### 4.2.1 整体布局

三栏结构：

| 区域 | 视觉 | 默认宽度（可调范围） | 内容 |
| --- | --- | --- | --- |
| 左栏 | 深色底、浅色字 | 250px（最小 150px），可滚动 | 上部「元素库」、下部「图层面板」 |
| 中栏 | 白色工具条 + 灰色画布区 | 自适应 | 顶部两行工具条，下方画布工作区 |
| 右栏 | 白底、左侧分隔线 | 300px（最小 200px），可滚动 | 「参数定义」与「元素属性」 |

- 新建态（无模板编号进入）：自动载入一份 A4（210×297）空白模板，名称「未命名模板」，**仅存在于内存中，首次点「保存模板」才写入模板库**。
- 打开不存在的模板：提示「模板不存在」并返回模板列表。
- **首屏性能策略**：打开设计器时工具条与左右面板先呈现并可立即操作（如直接改名称），画布区域短暂显示同底色加载占位后再载入，避免打开瞬间输入框卡顿。

#### 4.2.2 工具条

**第一行：模板基础信息**（各字段前有灰色标签文字）

- **名称**：标签「名称」并带红色必填星号，输入框宽 200px，直接编辑；编辑过程中允许临时清空，但保存时必须非空。
- **纸张**：标签「纸张」，按钮显示当前尺寸（如「210×297mm」），悬停提示「点击修改纸张尺寸」。点击弹出「纸张尺寸」气泡卡片：
  - 预设下拉：每项格式 `名称（宽×高mm）`，另含一项「自定义尺寸（毫米）」；
  - 「宽」「高」数字框：范围 5–2000，步进 1，后缀 mm；
  - 灰色说明原文：「元素不随纸张缩放；超出新边界的内容将在打印时被裁剪。」
- **分类**：标签「分类」，宽 130px 的可搜索下拉，可清空；可选已有分类，也可在下拉底部输入框输入新分类后回车创建（占位文案「输入新分类后回车」）。

**第二行：编辑与保存操作**

- 「撤销」「重做」按钮（始终可见，无历史时点击无效果）。
- 存在未保存修改时显示橙色「未保存」字样。
- 按钮随保存状态切换：

| 状态 | 显示按钮 |
| --- | --- |
| 已保存模板、无修改 | 「保存模板」、「去打印」（直接跳打印页）、「复制模板」 |
| 有修改 / 新建未保存 | 「保存模板」、「保存并去打印」；已保存模板另显示「复制模板」 |

- 「保存并去打印」在名称为空或模板校验不通过时禁用，鼠标悬停显示原因（如「模板名称不能为空」）。
- 保存规则：
  - 名称为空：提示「模板名称不能为空」；
  - 校验不通过：提示「保存失败：{具体原因}」；
  - 保存成功：提示「已保存」；新建模板保存后地址更新为正式模板，页面不刷新；
  - 保存时若模板引用了其他模板的图片（复制草稿场景），系统自动复制图片资源并回写引用，保证模板自包含。
- 「复制模板」：把当前模板复制为内存草稿（命名「原名副本」），提示「已复制为草稿，记得保存」。

#### 4.2.3 元素库（左栏上部）

标题「添加元素」，按钮自上而下：

1. 「横排文本框」
2. 「竖排文本框」
3. 「图片」
4. 「直线」
5. 「矩形」
6. 「椭圆」

两个文本按钮下方有灰色提示：`文本中用 {{参数名称}} 引用参数`。

新元素默认规格：

| 元素 | 默认位置 | 默认尺寸 / 内容 |
| --- | --- | --- |
| 横排文本框 | (20, 20) | 60×8mm，默认文字「右侧文本框编辑文本」 |
| 竖排文本框 | (20, 20) | 14×60mm |
| 图片 | (20, 60) | 宽固定 40mm，高按原图比例 |
| 直线 / 矩形 / 椭圆 | (20, 20) | 50×30mm |

图片元素规则：

- 支持格式：**PNG、JPG/JPEG、GIF、BMP**；非法文件给出「不支持的图片格式（仅 png/jpg/gif/bmp）」类提示。
- **新建模板首次保存前禁止添加图片**，以黄色警告提示：「请先点击「保存模板」完成新建，再添加图片」。
- 图片按原始比例插入；在画布上拖放缩放时锁定宽高比。

#### 4.2.4 画布工作区

**画布工具条**（画布区顶部）：

- 缩放控件：文字「缩放」＋「－」＋ 滑杆（宽 300px，范围 **20%–300%**，步进 **1%**）＋「＋」＋ 当前百分比整数显示。缩放只改变屏幕显示，不改变毫米数据。
- 「网格(2mm)」复选框：**默认关闭，且仅本次运行期间有效，不跨次启动记忆**。开启后纸面显示间距 2mm 的浅灰网格。

**画布视觉**：

- 灰色（#e9ecef）可滚动工作区，内边距 24px；白色纸张带投影，纸张外缘有 2px 深灰（#444）外边框，边框完全画在纸张外侧、不占纸面。
- 工作区最小宽 400px，纸张距舞台边缘留 40px。

**选择与变换**：

- 单击元素选中，单击纸张空白取消选中。
- 选中后出现变换外框：矩形、图片、文本有 8 个缩放锚点与 1 个旋转锚点；变换小于约 4px 自动回弹。
- 文本框宽高可分别拖拽（文字随框重新流动）；图片始终等比缩放；**直线与椭圆没有画布锚点，只能整体拖动，尺寸与角度需在右侧属性面板用数字修改**。
- 旋转以元素**左上角**为轴心，松手后角度保留 1 位小数。
- **双击文本元素**：不弹窗，直接选中该元素并让右侧属性面板的文本编辑框获得焦点（光标置于末尾）。
- 已锁定元素画布上不可拖动。
- 当前为**单选模型**：不支持多选、框选、组合、右键菜单、复制粘贴元素。
- 键盘操作：画布获得焦点时，`Delete` / `Backspace` 删除选中元素；无方向键微调、无键盘快捷键。

**对齐吸附与辅助线**：

- 拖动元素时，参照**纸张四条边界**与**其他所有元素**进行吸附。
- 参与对齐的候选线：拖动框与参照物各自的左、中、右（水平方向）和上、中、下（垂直方向）。
- 吸附阈值 **3mm**；每轴取最强的一条对齐，吸附时显示贯穿纸面的**红色辅助线**，松手消失。
- 开启网格时附加 **2mm 网格吸附**（网格吸附不受 3mm 阈值限制，且最后生效）。
- 拖动过程中画面实时跟随，松手才正式写入数据；坐标精确到 0.01mm。

#### 4.2.5 属性面板（右栏）

分为「参数定义」与「元素属性」两个区块（分隔线标题）；未选中元素时「元素属性」区显示灰色文字「未选中元素」。

**所有元素的公共几何属性**：

| 属性 | 控件 | 规则 |
| --- | --- | --- |
| X / Y | 数字框，后缀 mm，保留 1 位小数 | 元素左上角相对纸面的坐标，可为负值 |
| 宽 / 高 | 数字框，后缀 mm | 必须为正数，面板下限 1mm |
| 旋转 | 数字框，后缀 ° | 范围 -180～180，步进 15，绕左上角旋转 |
| 锁定 | 开关 | 开启后画布上不可拖动 |

**文本元素属性**：

| 属性 | 控件与规则 |
| --- | --- |
| 排版方向 | 分段控件「横排 / 竖排」，默认横排 |
| 列方向 | 仅竖排显示：「从右到左」（默认，传统版式）/「从左到右」 |
| 文本内容 | 2 行高文本域，可混排固定文字与 `{{参数名}}` 占位符 |
| 插入参数 | 模板已定义参数时出现下拉，占位文案「插入参数到文本末尾」；选择后把对应占位符追加到文本末尾（文本非空白结尾时自动补一个空格） |
| 字体 | 可搜索下拉，分三组：「系统默认（推荐）」、「常用字体」（本机已安装的微软雅黑、宋体、黑体、楷体、仿宋、Arial、Times New Roman、Calibri、Courier New、Segoe UI）、「全部字体」（枚举本机全部字体）；每个选项以其自身字体做预览 |
| 字号 | 数字框，单位 **pt**，最小 1pt，新建文本默认约 14.2pt（5mm） |
| 字形 | 粗体 B / 斜体 I / 下划线 U 三个开关式按钮 |
| 对齐 | 横排：左对齐 / 居中 / 右对齐（默认居中）；竖排时按物理方向映射为「右对齐 / 居中 / 左对齐」 |
| 行高 | 倍数数字框，最小 0.5，步进 0.1，默认 1.2 |
| 字色 | 取色器，默认黑色 #000000 |

**图片元素属性**：仅可编辑公共几何属性与锁定；画布与打印均按**等比完整显示（contain，居中、不拉伸、超出裁剪）**呈现。填充方式（完整显示/填满裁剪/拉伸）与不透明度在数据层面保留，当前版本界面无配置入口。

**图形元素属性**：

- 形状切换：直线 / 矩形 / 椭圆；
- 线宽：数字框，最小 0，步进 0.1mm，默认 0.3mm；
- 描边颜色：取色器，默认黑色；
- 填充颜色：可清空取色器，默认**无填充（透明）**；直线不使用填充。

#### 4.2.6 参数定义（右栏上部）

参数是**打印前需要填写的字段**，不直接出现在画布上，必须在文本中以 `{{参数名称}}` 引用才会生效。

- 入口：虚线按钮「添加参数」；下方提示原文：「参数不直接上画布；在文本中用 {{参数名称}} 引用。」
- 列表表格：列为「参数名称」「类型」「操作」（编辑 / 红色删除），按参数定义顺序排列，无分页。
- 新建参数自动命名「参数1」「参数2」……模板内自动避让重名。

**参数编辑弹窗**（新增标题「添加参数」、编辑标题「编辑参数」）：

| 表单项 | 规则 |
| --- | --- |
| 参数名称 | 必填。标签原文「参数名称（模板内唯一，可中文；文本中以 {{名称}} 引用）」。规则：去除首尾空格后 1–30 字符；不得包含 `{`、`}` 或换行；同一模板内唯一；允许中文。错误文案：重名「该名称已存在」、非法「名称不能为空且不能包含 { }」，不合法时「确定」禁用 |
| 类型 | 单行文本 / 多行文本 / 日期 / 数字/金额，四选一 |
| 必填 | 开关，默认开启 |
| 默认值 | 文本输入；标签原文「默认值（日期类型填 today 表示默认当天）」。日期参数填 `today` 时，打印页默认取当天日期 |
| 日期格式 | 仅日期类型显示，共 9 种预设，见附录 B |
| 数字格式 | 仅数字类型显示：「小数位」0–6（默认 2）、「千分位」开关（默认关） |
| 值为空时 | 「显示参数名称」（默认）/「留空白」/「打印占位横线」。打印时该参数为空：选「显示参数名称」则占位符位置直接输出参数名称本身（如 `{{姓名}}` 输出「姓名」，先打印后手写时兼作填写提示）；选「打印占位横线」则输出两个全角空格长度的下划线，供手工填写；选「留空白」则不输出任何内容 |

- 编辑改名时，底部灰字提示：「改名会同步替换文本中已引用的 {旧名称}。」确认后模板所有文本中的对应占位符批量替换。
- 删除参数需气泡确认，原文：`删除参数"{名称}"？文本中未替换的 {{名称}} 打印时将留空`；删除后文本元素保留，残留占位符打印时输出为空。

**占位符与求值规则**：

- 语法：双大括号包裹参数名，如 `{{姓名}}`；大括号内侧允许空白。
- 文本中引用了**参数表里不存在的名称（含已删除参数）时，打印一律替换为空，不报错、不保留原文**（不受下文空值策略影响）。
- 引用的参数**已定义但值为空**时，按该参数「值为空时」设置处理：显示参数名称（默认，输出参数名称原文）/ 留空白（输出空）/ 打印占位横线（输出两个全角空格宽的下划线）。
- 参数值在输出前统一做安全转义，保证用户填入的任何内容都只作为文字显示，不会破坏或篡改版式。
- 日期参数：无法解析的日期原样输出；数字参数：按小数位四舍五入、可选千分位；非数字内容原样输出。

#### 4.2.7 图层面板（左栏下部）

- 标题「图层（{元素数量}）」；无元素时显示「暂无元素」。
- 列表按图层层级**从高到低**排列（最上层在最上）；每项显示类型名：「文本（横）」「文本（竖）」「图片」「图形」。
- 单击图层项与画布选中双向联动；选中项蓝底高亮。
- 每项三个操作：锁定/解锁、「置顶」（层级提到最上）、删除。
- 拖拽整行可重新排序：拖到某一项上松手 = 插到该项之前；拖到面板空白处 = 置于最顶层；松手后层级重新编号并记录到撤销历史。
- 不提供图层显隐开关、图层重命名与分组文件夹。

#### 4.2.8 撤销 / 重做与未保存保护

- 任何成功的修改在执行前保存修改前快照，可连续撤销，**历史上限 50 步**；新操作会清空重做链。
- 不合法的修改（如参数名重复）会被拒绝，文档保持原状。
- 撤销/重做后清空当前选中并标记未保存。
- 以下修改均计入未保存状态与撤销历史：名称、纸张、分类、元素增删改、几何与样式调整、图层排序、参数增删改与改名（「复制为草稿」只标记未保存、不占历史栈）。
- **离开保护**：
  - 在应用内切换侧边导航：弹出应用风格确认框（见 4.2.9），确认后才离开；
  - 关闭窗口或刷新：触发系统级离开确认，文案一致。
- **草稿只存在于本次运行内存中，不做崩溃后自动恢复**：应用退出后未保存内容不保留。以下两类跨页面数据传递为一次性内存传递：
  - 从打印历史「重打」进入打印页时携带的模板快照与参数值，使用一次后清除；
  - 从打印页「调整版式」进入设计器再返回时，恢复此前已填的参数值，取回即清除。

#### 4.2.9 未保存确认弹窗

- 标题：「未保存的修改」
- 正文：「当前模板有未保存的修改，确定离开吗？」
- 按钮：「离开」（红色危险按钮）/「取消」（默认焦点落在「取消」，防误触）。

### 4.3 开始打印

#### 4.3.1 进入方式与空状态

- 常规入口：模板列表卡片「去打印」。
- 设计器入口：有未保存修改时为「保存并去打印」（先保存再跳转，校验不通过禁用）；无修改时为「去打印」直接跳转。
- 历史入口：「重打」携带历史模板快照与当时参数进入（无需依赖原模板仍存在）。
- 直接点侧边菜单「开始打印」而未选模板：提示「请先从模板列表选择要打印的模板」。
- 模板已不存在：提示「模板不存在」并返回列表；加载过程显示居中加载动画。

#### 4.3.2 页面布局

左右两栏：

- **左栏（宽 280px，白底）**：顶部模板名（三级标题），其下依次为参数填写表单、打印控制项与操作按钮。
- **右栏（灰底）**：实时预览。

#### 4.3.3 参数填写表单

- 参数按定义顺序纵向排列；标签为参数名，必填参数标签后带红色「 *」。
- 控件随参数类型变化：

| 参数类型 | 填写控件 |
| --- | --- |
| 单行文本 | 单行输入框（受最大字数限制） |
| 多行文本 | 2 行高文本域 |
| 日期 | 日期选择器，按参数设定格式呈现；默认值 `today` 自动填当天 |
| 数字/金额 | 数字输入框 |

- 初始值取参数默认值；必填项未填时输入框标红、下方提示「必填」；最终校验在点击打印时执行。

#### 4.3.4 实时预览

- 标题：「实时预览（{宽}×{高}mm）」，如「实时预览（80×200mm）」。
- 按模板毫米尺寸 1:1 物理比例渲染整页纸张（白底带阴影），随参数输入实时刷新。
- **预览始终显示完整版式（含图片、图形、边框）**：「仅打印文本」只影响实际打印输出，不影响预览，以便用户随时对照版式。
- 参数尚未填写时，占位符按该参数的「值为空时」设置呈现（默认直接显示参数名称），预览所见即打印所得。
- 缩放控件：「－」、滑杆（20%–300%，步进 1%）、「＋」与实时百分比。

#### 4.3.5 打印控制项

| 控件 | 规则 |
| --- | --- |
| 打印机 | 下拉枚举本机所有打印机；系统默认打印机名称后标注「（系统默认）」。默认选中优先级：模板上次使用的打印机 → 应用默认打印机 → 系统默认打印机 → 列表第一台 |
| 静默直打 | 开关。开启=不弹系统对话框直接输出；关闭=打印时弹出系统打印对话框由用户确认（可临时改纸张等）。开关状态按模板记忆 |
| 份数 | 数字框，1–99，默认 1 |
| 仅打印文本 | 开关，状态按模板记忆。开启后下方显示橙底提示：「选中后仅输出文字，不打印图片/图形/边框，适合已预印底图的纸张」 |
| 操作按钮 | 「打印」主按钮、「调整版式」次按钮（跳设计器，返回后已填参数保留） |

#### 4.3.6 打印提交流程

点击「打印」后依次执行：

1. **必填校验**：存在空值必填项时中止并提示「请填写必填项：{名称列表}」。
2. **打印机校验**：未选择打印机时提示「请选择打印机」。
3. **打印机状态检测**（见 4.3.7）：异常状态先征询用户。
4. **自定义纸张提示**（仅静默直打，见 4.3.8）：非标准纸张首次静默输出时引导确认。
5. **发送打印**：
   - 成功：提示「打印任务已发送」；
   - 用户在系统对话框中取消：提示「已取消打印」；
   - 失败：提示「打印失败：{原因}」。典型原因包括必填项缺失、模板引用的图片文件丢失（提示「模板引用的图片不存在（元素 {标识}），请重新上传后再打印」；「仅打印文本」模式下不校验图片）。
6. **无论成功、失败还是取消，都会生成一条打印历史**，并跳转到「打印历史」页查看结果。

#### 4.3.7 打印机状态检测

- 打印前自动读取所选打印机实时状态；读取失败时回落「状态未知」，不拦截打印。
- 异常状态分级与确认弹窗：

| 状态 | 含义 | 弹窗标题 |
| --- | --- | --- |
| 就绪 | 正常、处理中、等待中、忙碌等（绿点） | 不拦截 |
| 离线 | 脱机（灰点） | 「打印机状态：离线」 |
| 缺纸/耗材 | 缺纸、卡纸、无墨粉/墨粉不足、等待手动进纸等（黄点） | 「打印机状态：缺纸/耗材」 |
| 异常 | 错误、已暂停、需要用户干预等（红点） | 「打印机状态：异常」 |
| 状态未知 | 暂时无法获取状态（浅灰点） | 不拦截 |

- 异常弹窗正文：「打印机当前状态可能无法完成打印。仍要继续发送任务吗？」按钮「强制打印」/「返回」。

#### 4.3.8 自定义纸张输出提示（仅静默直打）

静默直打到非打印机驱动标准纸张（A4、A3、A5、B5、Letter 及其横向之外的尺寸，含小票、标签、自定义尺寸）时，首次对该「打印机 + 纸张尺寸」组合弹出引导：

- 标题：「自定义纸张输出提示」
- 正文要点：
  - 「当前模板纸张为 {宽}×{高} mm，将静默发送到打印机"{打印机名}"。」
  - 「若实际输出尺寸或位置不对：」
  1. 在 Windows「设置 → 蓝牙和设备 → 打印机和扫描仪」选中该打印机，进入「打印服务器属性」，按提示的毫米尺寸新建表单；
  2. 在打印机首选项中选用该表单；或改用「弹框打印」，在系统对话框中确认纸张。
- 勾选项：「本次仍要打印，且以后对此打印机+尺寸不再提示」（记住该组合，之后不再打扰）。
- 按钮：「仍要打印」/「取消」。弹框打印模式不显示此提示（用户可在系统对话框自行处理纸张）。

### 4.4 打印历史

#### 4.4.1 记录内容

每次提交打印（成功、失败、取消均记录）留存以下信息：打印时间、模板名称快照、**模板完整快照**（脱离原模板仍可重打）、当时填写的参数键值对、成品缩略图、打印机名称、份数、打印模式（静默/弹框）、结果状态、失败原因。

#### 4.4.2 列表展示

- 按时间倒序，每页 30 条。
- 列：时间（YYYY-MM-DD HH:mm）、缩略图（36px 宽，无图显示灰色「无」，点击可看大图）、模板、参数摘要（拼成「参数名=值，参数名=值」，无参数显示「—」）、打印机、状态、操作。
- 状态标签：绿色「成功」、灰色「已取消」、红色「失败」（失败标签悬停可查看具体失败原因）。
- 不提供单条删除、详情弹窗与导出（删除/清空统一在「打印机设置」中管理）。

#### 4.4.3 筛选区

| 筛选项 | 说明 |
| --- | --- |
| 模板 | 下拉，占位「全部模板」 |
| 日期范围 | 按所选日期 00:00–23:59 过滤 |
| 关键字 | 占位「搜索参数内容，如：张三」，同时匹配模板名与参数值 |
| 状态 | 多选：成功 / 失败 / 已取消，占位「全部状态」 |
| 打印机 | 下拉，占位「全部打印机」，选项来自历史中出现过的打印机 |
| 操作 | 「重置」清空全部筛选；右侧实时显示「共 N 条」；条件变化自动刷新 |

#### 4.4.4 重打与直接重发

## 五、核心业务流程

### 流程 1：从新建模板到打印成品

1. 首页点「新建模板」→ 进入设计器，得到一张 A4 空白模板。
2. 在「元素库」添加横排/竖排文本、图片与图形；在右栏「参数定义」中添加参数（如「姓名」「日期」）。
3. 在文本中通过「插入参数到文本末尾」或手写 `{{姓名}}` 引用参数；拖曳元素配合红色辅助线与 2mm 网格精确排版，可用图层面板调整叠放次序。
4. 点工具条「纸张」按钮选择预设或输入自定义尺寸（5–2000mm）。
5. 点「保存模板」，为模板命名（必填）、可选分类；首次保存后模板正式入库。
6. 点「去打印」或「保存并去打印」进入打印页：填写参数，预览实时更新。
7. 选择打印机、份数与打印模式（必要时开启「仅打印文本」套打）；状态异常时按引导决定是否强制打印。
8. 点「打印」→ 查看结果提示 → 自动跳转打印历史，本次任务留档。

### 流程 2：基于历史记录重打

1. 进入「打印历史」，按模板、日期、关键字、状态、打印机筛选定位记录。
2. 仅改个别内容：点「重打（可修改）」→ 在打印页改参数/打印机/份数 →「打印」。
3. 原任务失败且参数不变：点「直接重发」→ 确认后按原参数发送到原打印机。

### 流程 3：复用与迁移模板

- **本机复制改版**：模板卡片「更多 → 复制」（或设计器内「复制模板」）→ 得到「原名副本」草稿 → 改版式与参数 → 保存为独立模板。
- **跨电脑迁移**：卡片「更多 → 导出」得到 .tplx 文件；在另一台电脑首页「导入」，新模板命名自动追加「 导入」，图片随包迁移。
- **整体迁移（含历史与设置）**：在「打印机设置」中「立即备份」得到 zip 包，拷贝到目标机器的数据目录。

### 流程 4：打印中临时调整版式

1. 打印页填写参数后发现版式需调整 → 点「调整版式」进入设计器（已填参数被暂存）。
2. 修改并保存模板 → 返回打印页，**之前填写的参数自动恢复**，继续打印。
3. 若在设计器尝试不保存直接切走，触发「未保存的修改」确认。

### 流程 5：应用更新

1. 启动时自动检查或在「关于我们」手动检查 → 弹出「发现新版本」弹窗查看更新说明与包大小。
2. 「立即更新」→ 查看下载进度（可取消保留进度、断点续传）→ 自动校验完整性。
3. 确认「立即安装并重启」→ 允许 UAC 提示 → 自动备份、安装、校验、重启进入新版。
4. 若失败：应用自动回滚旧版并给出中文原因，可打开日志目录或联系开发者。

## 六、模板与参数设计规则（产品规格汇总）

### 6.1 模板级规格

| 项目 | 规则 |
| --- | --- |
| 名称 | 必填；保存时去除首尾空格不能为空；编辑过程允许临时清空 |
| 分类 | 可空；可从已有分类选择，也可输入新分类回车即时创建 |
| 纸张 | 宽、高以毫米计，自定义范围 5–2000mm，整数步进；新建默认 A4（210×297）纵向、零边距 |
| 改纸张 | 元素位置与尺寸保持不变（不随纸张缩放），超出新纸面的内容打印时裁剪 |
| 打印设置 | 每模板独立记忆：静默直打/弹框、仅打印文本、上次使用的打印机 |
| 时间信息 | 系统自动维护创建时间与最后更新时间 |
| 内置标记 | 系统示例模板带内置标记，随版本升级可被更新覆盖；用户自建与导入模板不受影响 |

### 6.2 元素规格

- 统一几何模型：X/Y（可为负）、宽/高（正数，面板下限 1mm）、旋转（-180～180°，步进 15，绕左上角）、锁定开关、图层层级（整数，数值越大越靠上）。
- 文本：支持固定文字与占位符混排；字体可选系统默认或本机任意已安装字体；字号以 pt 编辑（最小 1pt）；粗体/斜体/下划线；左/中/右对齐；行高倍数（≥0.5，步进 0.1，默认 1.2）；任意字色；横排或竖排；竖排可选列方向（默认从右到左）。
- 图片：PNG/JPG/GIF/BMP；等比完整显示、居中、超出裁剪；插入按原图比例、缩放锁定比例；图片以独立资源文件随模板保存，删除模板时连同图片删除；复制/导入模板时图片自动复制去关联。
- 图形：直线、矩形、椭圆；描边色（默认黑）、线宽（≥0，步进 0.1mm，默认 0.3mm）、填充色（可空=透明，直线无填充）。

### 6.3 排版规则

- **所见即所得**：设计器画布、打印预览、实际打印输出三者共用同一套版式规则，以毫米为唯一尺度，目标像素偏差不超过 1px。
- 横排文本：水平方向按左/中/右对齐，垂直方向在元素框内**垂直居中**；内容高度超出框时自动改为顶部起排，保证首行不被裁切；继续超出的部分裁剪不溢出。
- 竖排文本：汉字与拉丁字母、数字**一律正立**（非传统横躺样式）；默认从右向左排列，可切换为从左向右；预览与真实打印采用逐字按 1em 绝对定位统一排版，消除字体度量亚像素取整带来的垂直方向累积偏移。
- 换行：保留文本中的手动换行与连续空格；连续长串可自动断行。
- 下划线元素与文本自身的下划线均按 0.2mm 线宽输出。
- 所有元素超出纸面的部分在打印时裁剪。
- 打印固定为无边距输出，并精确输出背景与颜色（彩色块、印章色不失真）。

### 6.4 参数规格

| 项目 | 规则 |
| --- | --- |
| 参数名 | 1–30 字符，模板内唯一，可中文，禁止 `{`、`}` 与换行；自动命名「参数1」起；改名批量同步文本引用 |
| 类型 | 单行文本、多行文本、日期、数字/金额（不支持下拉、流水号、图片参数） |
| 必填 | 默认必填；打印时拦截空值并列出全部缺失项 |
| 默认值 | 可空；日期支持 `today` 表示当天 |
| 日期格式 | 9 种预设（附录 B）；无法解析的内容原样输出 |
| 数字格式 | 小数位 0–6（默认 2）四舍五入；可选千分位；非数字原样输出 |
| 空值策略 | 显示参数名称（默认）、留空白或打印占位横线（两个全角空格宽）；仅对已定义但未填写的参数生效，未定义引用一律输出空 |
| 未定义引用 | 文本中引用了不存在的参数名，打印时输出为空，不报错 |
| 填写顺序 | 按参数定义顺序展示在打印表单 |

### 6.5 模板文件（.tplx）

- 产品自有的模板交换文件，单个文件包含一份模板的全部版式定义、参数定义与该模板使用的全部图片源文件。
- 导出文件名默认 `<模板名>.tplx`；导入始终新建模板（名称追加「 导入」），不覆盖库内模板。

## 七、界面设计规范

### 7.1 布局与栅格

- 全局为「150px 深色侧导航 + 右侧内容区」；窗口最小 1024×700，低于此尺寸不再收缩。

### 7.3 表单规范

- 设计器工具条表单项采用「灰色小标签 + 控件」横向排列；弹窗表单标签在左。
- 必填项以红色星号标注；校验失败时控件标红并在下方给出中文错误短语（如「必填」），提交时再以提示消息汇总（如「请填写必填项：姓名、日期」）。
- 不满足条件的主按钮直接禁用，并通过悬停提示说明原因（如「模板名称不能为空」），而不是让用户点击后失败。
- 数字类输入必须标明单位与范围；非法输入（如宽高为 0）被忽略而非保存。

### 7.4 反馈与状态规范

- **即时轻提示**：操作成功/失败以页面顶部短提示反馈（已保存、已删除、打印任务已发送、备份完成：{文件名} 等），数秒后自动消失。
- **加载态**：页面级数据加载使用居中加载动画；重操作按钮在执行中转为加载状态不可重复点击（检查更新、备份等）。
- **空状态**：配空状态插画与一句引导文案，并指明下一步动作（如「还没有模板，点"新建模板"开始」）。
- **危险确认**：标题直接点明动作与对象（`删除模板"xxx"？`），正文说明后果与不可恢复性，危险按钮放右侧或使用红色，默认焦点在「取消」。
- **状态标签**：成功=绿色、失败=红色、取消=中性灰、警告/耗材=黄色；颜色不单独承载信息，同时配有文字。

### 7.5 弹窗文案结构

- 标题：动作 + 对象（必要时带状态），如「清理 90 天前的记录？」「打印机状态：离线」。
- 正文：先陈述事实/后果，再给出可选解决路径（自定义纸张提示是典型范例：先说明现状，再编号给出操作步骤，并提供替代方案）。
- 按钮：使用动词短语（「删除」「清理」「仍要打印」「强制打印」「离开」），不用笼统的「确定」；取消类统一「取消」。
- 高风险弹窗默认焦点在取消按钮，防止回车误触。

## 九、文案与反馈规范

- 全文使用简体中文，措辞简短直接，以用户能「照着做」为标准。
- 按钮文案为动词或动词短语，避免模糊的「确定」；危险操作按钮直接写明动作（「删除」「全部清空」「离开」）。
- 提示消息遵循「对象 + 结果」：「已保存」「已删除」「模板已导入」「备份完成：{文件名}」「测试页任务已发送」。
- 错误消息遵循「结论 + 可执行建议」：「打印失败：{原因}」「安装包已损坏或被篡改，已自动删除，请勿在非官方渠道获取更新。」
- 需要专业知识的场景提供**分步操作指引**（自定义纸张设置、UAC 授权提示），并给出替代方案（改用弹框打印、稍后安装）。
- 产品内保留的关键固定短语（设计模板时的提示语）：
  - `文本中用 {{参数名称}} 引用参数`
  - 「参数不直接上画布；在文本中用 {{参数名称}} 引用。」
  - 「元素不随纸张缩放；超出新边界的内容将在打印时被裁剪。」
  - 「选中后仅输出文字，不打印图片/图形/边框，适合已预印底图的纸张」

## 十、打印输出与版式一致性规范

1. **物理尺寸优先**：模板以毫米定义，预览按真实物理尺寸呈现；屏幕缩放（20%–300%）只影响查看，不影响输出。
2. **三端一致**：设计器画布、打印预览、实际打印共用同一套文字排版规则；换行位置、字距、基线、垂直居中在设计阶段即与成品一致（验收标准：各元素位置偏差不超过 1px）。
3. **文字为矢量输出**：任意缩放下文字边缘清晰，颜色精确输出（含背景色块）。
4. **无边距打印**：按纸张尺寸全幅输出，由模板元素自身决定留白。
5. **超出即裁剪**：元素超出纸面、文本超出元素框，一律裁剪，不自动分页、不自动溢出到第二张。
6. **套打模式语义**：「仅打印文本」时输出内容只有文字（图片、图形、边框全部跳过），但预览仍显示完整版式，用于和预印底纸对位。
7. **静默直打 vs 弹框打印**：前者追求效率、不打断操作，因此对非标准纸张事先引导；后者把纸张确认交给系统对话框，应用不重复打扰。
8. **打印必有留痕**：成功、失败、取消均入历史并附带成品缩略图，打印完成自动跳历史页形成闭环。

## 十一、数据、隐私与安全

### 11.1 数据存储

- 全部业务数据保存在本机当前 Windows 用户的私有数据目录下，包括：模板与参数定义、打印历史、图片源文件（按模板分目录存放）、打印缩略图、打印临时文件、应用设置。
- 打印临时文件在打印结束后即删除；缩略图可随历史记录重建。
- 应用不收集、不上传任何用户模板与打印内容；无账号、无云端同步。

### 11.2 数据保全

- **每日自动备份**：每天首次启动自动生成一份 zip 备份，保留最新 7 份；也可随时手动备份。
- 备份内容：全部模板（含内置示例）与参数定义、打印历史、图片源文件、应用设置；不含缩略图与已下载的更新安装包。
- 删除模板仅删除模板与其图片资源，**打印历史永久保留模板快照**，仍可查看与重打。
- 打印历史支持按 30/90/180 天/1 年自动清理（启动时执行）或手动清理，删除不可恢复，执行前二次确认。

### 11.3 更新安全

- 更新信息与安装包仅从官方渠道（含官方国内镜像）获取。
- 下载支持断点续传、空闲超时重试；安装包下载完成后强制校验完整性，损坏或被篡改的包自动删除、拒绝安装。
- 安装前自动备份当前版本；安装后校验新版本是否真正生效；失败自动回滚到旧版本并给出中文原因与日志入口。
- 安装过程最多触发一次 Windows UAC 授权，界面中事先明确告知。

### 11.4 误操作防护

- 删除模板、清理/清空历史均需二次确认并说明后果。
- 未保存修改时切换页面或关闭窗口均需确认，且默认按钮为「取消」。
- 高风险按钮在校验不通过时禁用，而非点击后报错。

## 附录 B：日期参数格式预设
